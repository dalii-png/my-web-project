## Screenshot Guidelines

1. Use full-screen or windowed screenshots as appropriate
2. Ensure no personal information is visible in any screenshot
3. For mobile screenshots, use device emulation in Chrome DevTools or actual device screenshots
4. Name files descriptively (e.g., "dashboard-desktop.png", "tasks-mobile.png")
5. Redact any sensitive browser extensions or other windows visible in screenshots
